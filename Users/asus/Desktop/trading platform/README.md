# 🎓 Ahmed Trader — Professional Trading Academy

A full-stack **professional online trading academy** built with modern web technologies, offering a complete Classical Technical Analysis curriculum, interactive lessons, gamification, and a premium learning experience.

## 🚀 Platform Features

- **Interactive Lessons** — Video + reading + TradingView practice exercises
- **Gamification System** — XP points, badges, leaderboards, streaks
- **Progress Tracking** — Per-lesson and per-module completion tracking
- **Admin Dashboard** — Full course management, student analytics, content editor
- **Quiz & Assessment Engine** — Auto-graded quizzes with revision triggers
- **Dark / Light Mode** — Full theme support
- **Responsive Design** — Desktop, tablet, and mobile optimized
